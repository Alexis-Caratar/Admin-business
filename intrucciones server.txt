para hacer copia de seguridad 
1- ingresaamos a db dentro de la carpeta y creamos temporal

sudo -u postgres pg_dump -d adminbusiness -F c -f /tmp/backup.dump
2. movemos a db
sudo mv /tmp/backup.dump ~/Admin-business/Bd/
y luego extraemos al local

3. comando para traer un archivo scp -i bakend_prod.pem ubuntu@3.227.242.168:/home/ubuntu/Admin-business/Bd/backup.dump .
